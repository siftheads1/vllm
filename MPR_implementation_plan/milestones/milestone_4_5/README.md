# Milestone 4.5

## Name

INT4 Packed Recovery Tier Integration

## Goal

Promote INT4 from a future extension into a first-class MPR precision tier
before Milestone 5 optimization. The target tier set is:

```text
fp16 / int8 / int4 / skip
```

Milestone 4.5 should add packed INT4 backup payloads, policy assignment,
payload lookup, recovery materialization, debug accounting, validator support,
and ratio-sweep smoke coverage.
